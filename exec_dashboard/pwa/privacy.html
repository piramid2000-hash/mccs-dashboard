원이엔지 경영 앱 개인정보처리방침

시행일: 2026년 12월 1일 · 운영: ㈜원이엔지 (ONE ENGINEERING CO.,LTD.)

'원이엔지 경영'(이하 앱)은 ㈜원이엔지 경영진이 회사의 공사 진척, 외주 진행, 수주·수금 현황을 확인하기 위한 사내 전용 앱입니다.

1. 수집하는 개인정보

앱은 이용자의 개인정보를 수집하지 않습니다. 회원가입, 이름·전화번호·이메일 입력, 위치·연락처·사진 접근, 광고 식별자 사용이 없습니다. 이용 통계나 분석 도구도 쓰지 않습니다.

2. 앱이 표시하는 자료

앱은 회사 내부 업무 자료(공사 일정, 외주 진행, 계약·수금·지급 금액)를 보여 줍니다. 이 자료는 암호화(AES-256-GCM)된 상태로 회사 웹 주소에서 내려받으며, 이용자가 입력한 비밀번호로 휴대폰 안에서만 풀어 화면에 표시합니다. 비밀번호와 풀린 자료는 서버로 전송되지 않습니다.

3. 휴대폰에 저장되는 것

  • '이 휴대폰에서 기억하기'를 켜면, 비밀번호 대신 밖으로 꺼낼 수 없는 암호 열쇠가 이 휴대폰의 앱 저장공간에 보관됩니다. 앱의 잠금(🔒) 버튼을 누르거나 앱 데이터를 지우면 삭제됩니다.
  • 인터넷이 끊겼을 때 보여 주기 위해 마지막으로 받은 암호화 자료와 앱 화면 파일이 저장됩니다.

4. 제3자 제공·위탁

개인정보를 제3자에게 제공하거나 처리 위탁하지 않습니다. 자료 파일은 GitHub Pages(GitHub, Inc.)를 통해 암호화된 상태로 전달됩니다.
