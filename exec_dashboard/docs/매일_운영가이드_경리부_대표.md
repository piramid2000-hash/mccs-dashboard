## A. 경리부가 할 일 (매일 5분)

폴더에 들어가는 파일은 두 종류입니다. 이름은 자유이고, 같은 이름으로 **덮어써도** 되고 날짜를 붙여 **새로 올려도** 됩니다. 앱은 가장 최근 파일을 읽습니다.

| 파일 | 내용 | 언제 고치나 |
|---|---|---|
| `업무현황.xlsx` (지금 쓰는 양식 그대로) | 공사별 승인도·발주·납품·설치·인도 일정, 발주업체 | 일정이 바뀐 날 |
| `수주수금.xlsx` (폴더의 `수주수금_입력양식.xlsx`를 복사해서 사용) | 3개 시트: 수주 / 수금 / 외주비 | 매일 (돈이 오간 날) |

### `수주수금.xlsx` 작성법
- **수주** 시트: 공사마다 한 줄. `수주일`, `수주금액(원)`.
- **수금** 시트: 공사마다 선금·중도금·잔금 줄이 미리 있음. `청구예정일`, `청구금액` 을 먼저 적어 두고,
  **돈이 들어온 날 `수금일`·`수금액`을 채운다.**
- **외주비** 시트: 외주업체 발주 1건당 한 줄. `업체`, `품목`, `발주금액`, `지급예정일`.
  **결제한 날 `지급일`·`지급액`을 채운다.** (나눠서 지급하면 지급액을 누적 금액으로 고치면 됨)
- 공사명은 업무현황 엑셀과 **똑같이** (예: `200톤 10척 3호정`). 다르면 앱의 '데이터 점검'에 표시됩니다.
- 금액은 숫자만, 또는 `1.2억`, `3,500만원` 도 인식. 날짜는 `2026-11-24` 또는 `26.11.24`.

### 올리는 방법 (둘 중 편한 것)
1. **구글 드라이브 데스크톱 앱** 설치 → PC에 생긴 `G:\내 드라이브\원이엔지_업무현황` 폴더에서 엑셀을 바로 열고 저장 (가장 편함, 저장=업로드)
2. 웹 drive.google.com → 폴더 열기 → 파일 끌어다 놓기 → "새 버전으로 바꾸기/둘 다 유지" 아무거나

> 퇴근 전까지만 올리면 됩니다. 이틀 넘게 새 파일이 없으면 아침 메일 맨 위에 "업로드 확인" 경고가 붙습니다.

## B. 대표가 받는 아침 메일 (설정은 한 번)

메일 내용: ① 한 줄 요약(수금 N건 ○억 입금 / 외주 결제 N건 / 일정 지연) ② 어제 이후 들어온 돈 ③ 나간 외주 결제
④ 늦춰진 일정 ⑤ 7일 내 받을 돈·줄 돈 ⑥ 확인 필요 공사, 그리고 **첨부 HTML** (카톡으로 그대로 전달 가능).

### B-1. 보내는 메일 계정에 '앱 비밀번호' 만들기 (Gmail 기준, 3분)
1. 보낼 Gmail 계정으로 myaccount.google.com → **보안** → **2단계 인증** 켜기 (이미 켜져 있으면 통과)
2. 같은 화면 검색창에 **앱 비밀번호** → 이름 `아침 브리핑` → 만들기 → 16자리 비밀번호 복사
   (일반 로그인 비밀번호가 아닙니다. 이 16자리만 사용)

### B-2. GitHub에 비밀값 넣기 (5분)
github.com/piramid2000-hash/mccs-dashboard → **Settings → Secrets and variables → Actions → New repository secret**
아래 5개를 하나씩 추가 (이름은 정확히 똑같이):

| 이름 | 값 |
|---|---|
| `GDRIVE_FOLDER_ID` | 드라이브 폴더 주소의 `folders/` 뒤 문자열 |
| `GDRIVE_SERVICE_ACCOUNT` | 서비스 계정 JSON 키 파일 내용 전체 (구글드라이브 가이드 2단계) |
| `SMTP_USER` | 보내는 Gmail 주소 |
| `SMTP_PASSWORD` | B-1의 16자리 앱 비밀번호 |
| `BRIEF_TO` | 받는 사람 메일 (여러 명이면 쉼표로: `대표@…,이사@…`) |
| `DASHBOARD_URL` (선택) | 대시보드 앱 주소 → 메일에 '대시보드 열기' 버튼이 생김 |

Secrets 값은 저장소가 공개여도 **아무도 볼 수 없습니다** (입력한 본인도 다시 못 봄).

### B-3. 시험 발송
GitHub 저장소 → **Actions** 탭 → 왼쪽 **아침 브리핑** → **Run workflow** → 초록 체크가 뜨면 메일함 확인.
- 첫 메일은 비교 대상이 없어 "오늘 현황만" 나옵니다. 다음 날부터 '어제 대비 변화'가 채워집니다.
- 실패(빨간 X)하면 해당 실행을 눌러 로그 마지막 줄을 보세요:
  `업무 현황 엑셀을 찾지 못했습니다` → 폴더 공유/ID 확인, `Username and Password not accepted` → 앱 비밀번호 확인.

### 알아둘 점
- 발송 시각: 월~금 **07:17 전후** (GitHub 사정으로 5~30분 늦을 수 있음). 월요일 메일은 금요일 대비 변화.
- 발송 시각 변경: `.github/workflows/morning-brief.yml` 의 `cron` 한 줄 (UTC 기준, 한국시간 −9시간).
- GitHub는 **60일간 저장소에 변경이 없으면** 예약 실행을 멈춥니다. 멈추면 Actions 탭에서 다시 켜기(Enable) 한 번.
- 로그에는 건수만 남고 금액·공사명은 남지 않습니다 (저장소가 공개라서).
- 카톡 자동 발송은 카카오 개발자 등록·토큰 갱신이 필요해 넣지 않았습니다. 메일의 첨부 HTML을 카톡으로 전달하세요.
