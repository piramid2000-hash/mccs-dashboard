# 원이엔지 경영 — 스마트폰 앱 설치 가이드

홈 화면 아이콘을 누르면 앱처럼 전체 화면으로 열립니다. 아이폰·갤럭시 모두 됩니다.
앱스토어를 거치지 않는 **설치형 웹앱(PWA)** 이라 심사·연회비가 없고, 고치면 다음 날 자동으로 반영됩니다.

```
경리부·직원 ──엑셀──▶ 구글 드라이브 '원이엔지_업무현황'
                          │  평일 07:05 / 19:40 자동 실행 (GitHub Actions)
                          ▼
             최신 엑셀 읽기 → 보고서 → 비밀번호로 암호화 → 앱 주소에 올림
                          ▼
        대표 휴대폰 '원이엔지' 앱: 비밀번호 한 번 → 이후 아이콘만 누르면 열림
```

## 화면
| 탭 | 내용 |
|---|---|
| 홈 | 핵심 숫자(진행 공사·수주·수금·미수), 오늘 아침 브리핑(어제 이후 들어온 돈·나간 돈·지연), 확인 필요, 앞으로 30일 |
| 공사 | 공사별 카드(위험·임박 순, 누르면 전체 일정), 공정 일정표 |
| 외주 | 외주 진척표, 업체 주의사항, 외주업체 결제(발주·지급·미지급·다음 지급일) |
| 자금 | 공사별 수주·수금·미수 |
| 점검 | 엑셀 작성 오류·불일치 (빨간 숫자 = 확인할 건수) |

상단의 ⟳ 는 새로고침, 🔒 는 잠그기(이 휴대폰에서 비밀번호 지우기). 인터넷이 없어도 마지막으로 받은 자료가 보입니다.

---

## 1. 처음 한 번 설정 (대표님 또는 담당자, 10분)

앞의 [매일 운영 가이드](매일_운영가이드_경리부_대표.md) B-2 에서 넣은 Secrets 에 **하나만 추가**합니다.

1. github.com/piramid2000-hash/mccs-dashboard → **Settings → Secrets and variables → Actions → New repository secret**
   - 이름 `APP_PASSWORD`, 값: 앱 비밀번호 (**12자 이상**, 예: 문장처럼 `원이엔지2027수주목표!`)
2. **Settings → Pages** → Build and deployment 의 **Source** 를 **GitHub Actions** 로 선택 (저장 버튼 없음, 선택하면 끝)
3. **Actions** 탭 → 왼쪽 **매일 업데이트** → **Run workflow** → 초록 체크 2개(build, deploy)가 뜨면 완료
4. 앱 주소: **https://piramid2000-hash.github.io/mccs-dashboard/**

> 비밀번호를 바꾸려면 `APP_PASSWORD` 만 고치고 Run workflow. 휴대폰 앱은 다음에 열 때 새 비밀번호를 묻습니다.
> 비밀번호를 잃어버린 직원 휴대폰에서 더는 못 보게 하려면 이 방법으로 바꾸면 됩니다.

## 2. 휴대폰에 설치 (1분)

**아이폰** (반드시 사파리)
1. 사파리에서 앱 주소 열기 → 비밀번호 입력 → **열기**
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → 이름 `원이엔지` → 추가

**갤럭시** (크롬 또는 삼성 인터넷)
1. 앱 주소 열기 → 비밀번호 입력 → **열기**
2. 화면 위에 뜨는 **설치** 버튼, 또는 메뉴 ⋮ → **앱 설치 / 홈 화면에 추가**

이후에는 홈 화면의 파란 아이콘만 누르면 바로 열립니다 ('이 휴대폰에서 기억하기'를 켠 경우).

## 3. 보안
- 앱 주소는 공개 웹이지만, 자료(`data.enc`)는 **AES-256 으로 암호화**되어 있어 비밀번호 없이는 내용을 볼 수 없습니다.
  비밀번호는 서버로 전송되지 않고 휴대폰 안에서만 자료를 풉니다.
- '기억하기'를 켜면 비밀번호 대신 **꺼낼 수 없는 열쇠**만 그 휴대폰에 저장됩니다. 휴대폰을 바꾸거나 분실하면 위 방법으로 비밀번호를 바꾸세요.
- 외주업체 담당자 전화·메일은 앱에 넣지 않습니다.
- 비밀번호가 짧으면 추측당할 수 있으니 12자 이상 문장형을 권합니다.

## 4. 안 될 때
| 증상 | 확인 |
|---|---|
| 앱 주소가 404 | Settings → Pages Source 가 GitHub Actions 인지, Actions 의 deploy 가 성공했는지 |
| "비밀번호가 맞지 않습니다" | `APP_PASSWORD` 와 같은지 (대소문자·띄어쓰기) |
| 자료가 어제 그대로 | 상단 '업데이트 시각' 확인 → Actions 실행 기록. 경리부 업로드 여부 |
| 아이폰에서 홈 화면 추가가 안 보임 | 카톡 안 브라우저가 아니라 **사파리**로 열었는지 |
