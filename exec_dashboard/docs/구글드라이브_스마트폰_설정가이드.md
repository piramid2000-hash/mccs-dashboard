# 구글 드라이브 연결 + 스마트폰으로 보기 — 단계별 가이드

전체 그림:

```
직원 ──엑셀 올림──▶ 구글 드라이브 '업무현황' 폴더
                         │ (읽기 전용, 서비스 계정)
                         ▼
             Streamlit Community Cloud (무료 서버)에서 대시보드 실행
                         │  https://○○○.streamlit.app  + 비밀번호
                         ▼
                 대표 스마트폰 / PC 브라우저
```

소요 시간: 처음 한 번 30~40분. 준비물: 구글 계정, GitHub 계정(이미 있음).

---

## 1단계. 구글 드라이브에 공유 폴더 만들기 (5분)

1. drive.google.com → **새로 만들기 → 새 폴더** → 이름 `업무현황`.
2. 폴더 우클릭 → **공유** → 엑셀 올릴 직원 이메일 추가, 권한 **편집자**.
3. 폴더를 열고 주소창 URL을 복사해 둔다.
   `https://drive.google.com/drive/folders/`**`1AbCdEfGh...`** ← 굵은 부분이 **폴더 ID**.
4. 직원에게 안내: "업무 현황 엑셀은 이 폴더에 올려 주세요. 같은 이름으로 덮어써도 되고 날짜를 붙여 새로 올려도 됩니다.
   수주·수금 양식도 같은 폴더에 올려 주세요."

> 드라이브 설정에서 "업로드 파일을 Google 문서 형식으로 변환"이 켜져 있어도 괜찮습니다. 구글 스프레드시트도 읽습니다.

## 2단계. 구글 클라우드에서 '읽기 전용 로봇 계정(서비스 계정)' 만들기 (10분)

대시보드 서버가 드라이브를 읽으려면 전용 계정이 필요합니다. 비용은 들지 않습니다.

1. **console.cloud.google.com** 접속 (같은 구글 계정으로 로그인). 처음이면 약관 동의.
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `wonieng-dashboard` → 만들기 → 만든 프로젝트 선택.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용** 클릭.
4. **IAM 및 관리자 → 서비스 계정 → + 서비스 계정 만들기**
   - 이름: `dashboard-reader` → **만들고 계속하기**
   - 역할(권한) 단계는 **비워 두고** 계속 → **완료**
5. 만들어진 서비스 계정을 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 만들기.
   `wonieng-dashboard-xxxx.json` 파일이 다운로드됩니다.
   ⚠️ 이 파일은 비밀번호와 같습니다. 메일·카톡으로 보내거나 GitHub에 올리지 마세요.
6. 서비스 계정 화면의 이메일 주소를 복사: `dashboard-reader@wonieng-dashboard.iam.gserviceaccount.com`

> "조직 정책으로 키 생성이 차단됨" 메시지가 나오면 회사 Google Workspace 관리자 정책 때문입니다. 개인 Gmail 계정으로 프로젝트를 만들거나 관리자에게 해제를 요청하세요.

## 3단계. 드라이브 폴더를 서비스 계정에 공유 (1분)

1. 드라이브의 `업무현황` 폴더 → **공유**.
2. 2-6에서 복사한 서비스 계정 이메일 붙여넣기 → 권한 **뷰어** → "알림 보내기" 체크 해제 → 공유.

## 4단계. 연결 시험 (선택, PC에 파이썬이 있을 때)

```bash
pip install -r exec_dashboard/requirements.txt
python exec_dashboard/scripts/test_drive.py 다운로드한키.json "폴더 URL 또는 폴더 ID"
```
`✓ 엑셀 N개 발견 / ✓ 최신 파일 읽기 성공` 이 나오면 성공. 실패하면 원인(API 미사용, 공유 누락 등)을 알려 줍니다.

## 5단계. 무료 서버(Streamlit Community Cloud)에 올리기 (10분)

1. **share.streamlit.io** → **Continue with GitHub** 로 로그인 → 저장소 접근 허용.
2. 오른쪽 위 **Create app** → GitHub 저장소에서 배포하는 항목 선택
   - Repository: `piramid2000-hash/mccs-dashboard`
   - Branch: 대시보드 코드가 있는 브랜치 (main 에 합친 뒤라면 `main`)
   - Main file path: `exec_dashboard/app.py`
   - App URL: 예) `wonieng-ceo` → `https://wonieng-ceo.streamlit.app`
3. **Advanced settings → Secrets** 칸에 아래를 붙여넣기 (값은 본인 것으로):

   ```toml
   APP_PASSWORD = "대표님만 아는 비밀번호"
   GDRIVE_FOLDER_ID = "1단계에서 복사한 폴더 ID"

   GDRIVE_SERVICE_ACCOUNT = '''
   { 2단계에서 받은 JSON 파일을 메모장으로 열어 전체 내용을 그대로 붙여넣기 }
   '''
   ```
   - JSON은 반드시 작은따옴표 3개 `'''` 사이에 넣습니다 (키 안의 `\n` 이 그대로 보존됨).
4. **Deploy**. 2~3분 뒤 앱이 뜨면 비밀번호 화면 → 로그인 → 왼쪽 메뉴에 **"Google Drive 폴더"** 가 선택되어 있으면 연결 완료.
5. Secrets를 나중에 바꾸려면: share.streamlit.io → 앱 옆 **⋮ → Settings → Secrets**.

### ⚠️ 보안: 반드시 읽어 주세요
- 현재 GitHub 저장소 `mccs-dashboard` 는 **공개(public)** 입니다. 공개 저장소에서 배포한 앱은 **주소만 알면 누구나 접속**할 수 있으므로 `APP_PASSWORD` 를 꼭 설정하세요.
  (코드만 공개되고, 엑셀·금액·연락처·키는 저장소에 올라가지 않습니다.)
- 더 안전하게 하려면: GitHub 저장소 **Settings → General → Change visibility → Private** 로 바꾼 뒤,
  Streamlit 앱 **Settings → Sharing → "Only specific people can view this app"** 에서 대표·임원 이메일만 초대하세요.
  그러면 구글 로그인한 초대자만 들어올 수 있습니다 (비밀번호와 함께 이중 잠금).

## 6단계. 스마트폰 홈 화면에 앱처럼 추가 (1분)

- **아이폰(사파리)**: 앱 주소 접속 → 아래 공유 버튼 □↑ → **홈 화면에 추가** → 이름 `경영 대시보드`.
- **갤럭시(크롬/삼성 인터넷)**: 앱 주소 접속 → 오른쪽 위 ⋮ → **홈 화면에 추가**.

휴대폰으로 접속하면 자동으로 **휴대폰 화면**으로 바뀝니다:
- 핵심 숫자 6개가 2열 카드로, 맨 위에 **대표 확인 필요 → 앞으로 30일 → 공사별 카드(위험 순)**.
- 차트는 공사명을 짧게(예: `10척 3호`), 일정 차트는 기준일 전후 15개월만 표시.
- 손가락 스크롤이 차트에 걸리지 않도록 확대/이동 기능은 꺼져 있습니다. 막대를 톡 누르면 상세가 나옵니다.
- PC에서 휴대폰 화면을 보고 싶거나 반대로 하고 싶으면 왼쪽 메뉴 **📱 휴대폰 화면** 스위치.

## 자주 묻는 것

| 증상 | 해결 |
|---|---|
| 앱에 "Google Drive 폴더" 선택지가 없음 | Secrets 에 `GDRIVE_FOLDER_ID`, `GDRIVE_SERVICE_ACCOUNT` 둘 다 있는지 확인 |
| "Google Drive 읽기 실패 … has not been used" | 2-3 단계 Drive API **사용** 클릭 후 2분 기다리기 |
| "엑셀을 찾지 못했습니다" | 3단계 폴더 공유 누락 / 다른 폴더 ID |
| 직원이 올렸는데 화면이 그대로 | 최대 1분 캐시 + 확인 주기(기본 5분). 브라우저 새로고침하면 즉시 반영 |
| 한동안 안 쓰면 "앱이 잠들어 있음" | 무료 서버는 며칠 접속이 없으면 잠듭니다. **Yes, get this app back up** 누르면 1분 내 재가동 |
| 변경 이력이 사라짐 | 무료 서버는 재시작 시 저장 파일이 초기화됩니다. 이후 올라오는 버전부터 다시 비교 |
| 접속할 때마다 비밀번호 | 브라우저 탭을 새로 열 때마다 한 번 입력합니다 (보안상 의도) |
