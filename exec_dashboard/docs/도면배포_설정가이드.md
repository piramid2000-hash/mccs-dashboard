# 도면 개정 카톡 배포 · 수령 확인 · 현장 QR — 설정과 사용법 (시제품)

```
[설계·사무]  도면대장.xlsx 에 개정 한 줄 + PDF 를 드라이브 폴더에 올림
     │  (평일 07:05 / 19:40 자동 업데이트 — 경영 앱과 같은 자동 실행)
     ▼
[대표 앱 '도면' 탭]  수신자별 [카톡 보내기] → 카카오톡 선택 → 외주사·현장반장에게 링크 전송
     ▼
[받은 사람]  링크 열기 → "✓ 최신 판입니다" + 최신 PDF → [수령 확인했습니다]
     │  (구글 앱스 스크립트가 '수령확인' 시트에 기록 → 다음 업데이트 때 앱에 ✓)
     ▼
[현장]  도면에 붙인 QR 스캔 → 최신이면 초록, 옛 판이면 "⚠️ 옛 판입니다. 사용하지 마세요"
```

## 1. 처음 한 번 설정 (약 20분)

### 1-1. 비밀값 만들기 (GitHub Secrets)
저장소 **Settings → Secrets and variables → Actions → New repository secret**
- `DOC_SECRET`: 아무도 모르는 긴 문자열 32자 이상 (예: 비밀번호 관리자 앱의 '무작위 생성').
  모든 도면 링크·QR 의 열쇠가 여기서 만들어집니다. **바꾸면 이미 보낸 링크와 붙인 QR 이 모두 무효**가 되니 처음 정한 값을 유지하세요.

### 1-2. 도면대장 올리기
1. 전달받은 `도면대장_양식.xlsx` 를 열어 확인합니다. 업무현황 엑셀의 도면 날짜로 **초안**을 채워 두었습니다
   (도면번호·Rev 는 회사 실제 값으로 고쳐 주세요. 사업부 규칙: 승인도 Rev A·B·C…, 공사도 Rev 1·2·3…).
2. `배포처` 시트: 카톡을 받을 사람·업체를 적습니다 (키 = 짧은 이름, 이름·회사·역할). 전화번호는 필요 없습니다.
3. 파일 이름을 `도면대장.xlsx` 로 해서 드라이브 `원이엔지_업무현황` 폴더에 올리고, 도면 PDF 도 **같은 폴더**에 올립니다.

### 1-3. 수령 확인 기록기 (구글 앱스 스크립트, 무료)
1. 같은 드라이브 폴더에서 **새로 만들기 → Google 스프레드시트**, 이름 `수령확인`.
2. 그 시트에서 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 저장소의 `exec_dashboard/apps_script/수령확인.gs` 내용 전체를 붙여넣기 → 저장(💾).
3. 왼쪽 **프로젝트 설정(⚙)** → 맨 아래 **스크립트 속성 추가**: 속성 `DOC_SECRET`, 값 = 1-1 과 **똑같은 값**.
4. 오른쪽 위 **배포 → 새 배포** → 톱니 → **웹 앱** → 실행: **나** · 액세스 권한: **모든 사용자** → 배포 → 구글 계정 권한 허용 → **웹 앱 URL 복사**.
5. GitHub Secrets 에 `ACK_URL` = 그 URL.

> 받은 사람(외주사)은 구글 로그인 없이 [수령 확인]을 누를 수 있습니다. 링크마다 서명이 있어, 주소를 조작하면 "확인할 수 없는 링크"로 거절됩니다.

### 1-4. 실행
Actions → **매일 업데이트** → Run workflow. 끝나면 대표 앱 하단에 **도면** 탭이 생깁니다.

## 2. 평소 쓰는 법

**도면이 개정되면 (설계·사무 담당)**
1. `도면대장.xlsx` 에 새 줄 추가: 같은 도면번호, 새 Rev, 승인일, 개정내용, 파일 이름, 배포처. (옛 줄은 지우지 말고 둡니다: 개정 이력이 됩니다)
2. 새 PDF 를 같은 폴더에 올립니다.
3. 다음 자동 업데이트(07:05 / 19:40) 뒤, 또는 Actions 에서 바로 Run workflow.

**배포 (대표 또는 담당자, 휴대폰)**
- 앱 → **도면** 탭 → 개정된 도면 카드 → 수신자 옆 **[카톡 보내기]** → 공유 화면에서 **카카오톡** → 받을 사람 선택.
  메시지에 공사·도면·Rev·개정 내용과 그 사람 전용 링크가 들어갑니다.
- PC 에서 누르면 메시지+링크가 복사됩니다 → PC 카톡에 붙여넣기.
- 받은 사람이 [수령 확인]을 누르면, 다음 업데이트 때 카드에 **✓ 확인 11.24 09:12** 로 바뀝니다. 탭의 빨간 숫자 = 아직 확인 안 한 사람 수.

**배포용 PDF (QR 이 찍힌 도면)**
- 자동 업데이트 때 최신 도면 PDF 의 **모든 쪽 모서리**에 QR + 도면번호·Rev·승인일 도장이 찍힙니다 (`○○_배포용.pdf`).
- 받은 사람이 링크에서 PDF 를 열어 출력하면 QR 이 이미 찍혀 있습니다. 나중에 새 판이 나오면 그 종이를 스캔했을 때 빨간 "옛 판" 경고가 뜹니다.
- 기본 위치는 오른쪽 위입니다. 표제란·개정표를 가리면 도면대장 **QR위치** 칸에서 우하·좌상·좌하로 바꾸세요.
- 원본 PDF 는 건드리지 않습니다 (배포용은 앱 안에서만 새로 만듦). 암호가 걸린 PDF 는 도장 없이 원본을 넣습니다.

**현장 QR 라벨** (이미 출력해 둔 종이 도면용)
- 도면 탭 → **QR 라벨 인쇄** → 인쇄 (PC 브라우저 권장, 라벨 스티커 용지).
- 출력한 도면의 표제란 옆에 붙입니다. 스캔하면 그 종이의 Rev 가 최신인지 바로 보입니다.
- 새 판이 나오면 새 도면에 새 라벨을 붙이세요. **옛 종이의 QR 은 그대로 두면 됩니다**: 스캔하면 "옛 판" 경고가 뜹니다.

## 2-1. 도면 외 문서에 QR 발행 (시험성적서·MSDS·작업표준서·점검표)
Claude 에게 "이 성적서에 QR 찍어줘"라고 하면 `doc-qr-issuer` 스킬이 아래 명령을 대신 실행합니다.
```bash
DOC_SECRET=... APP_URL=https://<계정>.github.io/<저장소>/ \
python exec_dashboard/scripts/issue_doc.py 성적서.pdf --type 시험성적서 --no TR-2026-0142 --title "성능시험" \
  --rev 1 --fields "시험일=2026-11-20; 결과=합격" --registry "<드라이브 폴더>/문서등록부.xlsx"
```
- 워드·엑셀·파워포인트·그림·PDF → PDF 로 바꿔 모든 쪽에 QR 도장 (`_발행본.pdf`). PC 에 LibreOffice 가 있어야 워드·엑셀이 변환됩니다.
- **전자서명·암호 PDF** 는 서명이 깨지지 않게 원본을 그대로 두고 `_확인표지.pdf` 한 장을 따로 만듭니다.
- **한글(HWP)** 은 한글에서 [PDF로 저장하기] 후 그 PDF 로 발행하세요.
- `문서등록부.xlsx` 와 발행본을 업로드 폴더에 두면 다음 자동 업데이트 때 QR 이 열리고, 대표 앱 '문서' 탭에 함께 보입니다.
- QR 을 찍은 사람은 최신 판 여부, 핵심값, 그리고 받은 파일이 원본과 같은지(지문 대조, 파일은 휴대폰 밖으로 나가지 않음)를 확인합니다.

## 3. 보안
- 링크·QR 에는 **그 도면 하나만 여는 열쇠**가 들어 있습니다. 다른 도면, 경영 자료(금액)는 열리지 않습니다.
- 링크를 다른 사람에게 전달하면 그 사람도 그 도면을 볼 수 있습니다 (종이 도면을 건네는 것과 같음). 민감한 도면은 배포처를 좁히세요.
- 도면 번호는 주소에 드러나지 않고, 도면 파일은 암호화되어 올라갑니다.
- 대표 앱의 '도면' 탭(모든 수신자 링크 포함)은 대표 앱 비밀번호로만 열립니다.

## 4. 시제품의 한계 (다음 단계 후보)
| 지금 | 다음 단계 |
|---|---|
| 카톡은 담당자가 [카톡 보내기]로 직접 전송 | 카카오 비즈니스 채널 + 알림톡으로 개정 시 자동 발송 (딜러사 계약·템플릿 심사·건당 요금) |
| 수령 확인은 다음 자동 업데이트 때 앱에 반영 | 수령 확인 즉시 반영 (앱스 스크립트가 업데이트를 바로 실행) |
| ✓ 배포용 PDF 에 QR 자동 도장 (완료) | 회사 도장·'배포용 사본' 워터마크, 받는 사람 이름 표시 |
| 링크 만료 없음 | 수신자별 만료일·열람 기록 |
| PDF 8MB 까지 앱에 포함 | 큰 도면은 드라이브 원본 링크로 |
