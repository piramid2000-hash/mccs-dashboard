# 특허출원 서류 (KIPO 서식)

Q-HSRS Phase 3 역설계 결과에 기초한 특허명세서 및 출원 도면.

| 파일 | 내용 |

| `QHSRS_특허명세서.md` | 명세서 전문 — 발명의 명칭 / 기술분야 / 배경기술 / 해결하고자 하는 과제 / 과제의 해결 수단 / 발명의 효과 / 도면의 간단한 설명 / 발명을 실시하기 위한 구체적인 내용 / 부호의 설명 / 청구범위(26항) / 요약서 / 대표도 |
| `QHSRS_도면.pdf` | 출원 첨부 도면 18매, 1매 1도면 |

| `make_patent_figs.py` | 도 1 ~ 도 18 작도 스크립트 |
| `make_spec.py` | 명세서 생성 스크립트 (실시예 수치를 설계 모듈에서 직접 산출) |

## 도면 규격 준수 사항

* 흑백 선화만 사용. 색채·음영·계조를 쓰지 아니한다.
* 선 굵기 균일 (외형선 1.1 pt, 인출선·해칭 0.6 pt).
* 단면부는 45° 평행 해칭으로 표시하고, 재질이 다르면 해칭 방향과 간격을 달리한다.
* 설명문자는 기재하지 아니하되, 블록도·흐름도·회로도·그래프에는 필요한 문자를 기재한다
  (도면 작성 요령 제3조 단서).
* 참조부호는 인출선으로 대상을 지시하고, 모든 도면에서 동일 부호는 동일 부재를 가리킨다.
* 도면 상단에 【도 n】을 표기한다.

## 청구범위 구성

* 청구항 1 — 장치 독립항. **도전성 저장조가 자속 경로의 외부에 배치되고 자속이 저장조
  벽체를 통과하지 아니하는 구성**이 핵심 특징.
* 청구항 2 — 셀별 독립 환류 경로에 의한 동일 극성 여자 및 자속밀도 영점의 부존재.
* 청구항 3, 4, 5 — 노출 제어 체적의 정의, 기준 위치 전달계수, 변동계수 10 % 이하.
* 청구항 6 ~ 9 — 자기저항 배분, 자극면 대 공극 치수비, 습부 외부 배치, 리츠선 소선경.
* 청구항 10, 11 — 대역 전환 직렬 보상부 및 **의도적 이조에 의한 부하 Q 제한**.
* 청구항 12 ~ 14 — 3계층 계측, 상호 검증에 의한 차단, 주파수 종속 복조 구간.
* 청구항 15 — 하드와이어 인터록 (소프트웨어에 의한 유지 불가).
* 청구항 16, 17 — 통전되는 바이파일러 상쇄 권선 대조부 및 회차별 잔류 자장 실측.
* 청구항 18 ~ 20 — 광섬유 온도 센서, 나노결정질 자심, 코리올리식 유량계.
* 청구항 21 ~ 25 — 제어 방법 독립항 및 종속항. 청구항 24는
  **누적 노출 시간 = 운전 시간 × 노출 제어 체적 / 저류 체적** 의 노출량 관리.
* 청구항 26 — 대조 운전에 의한 검증 방법 독립항.

## 반드시 확인하여야 할 사항

1. **선행기술조사가 수행되지 아니하였다.** 명세서 [0005] 및 [0006]의 선행기술문헌
   항목은 공란이며, 출원 전에 변리사의 선행기술조사 결과로 채워져야 한다. 조사 결과에
   따라 청구항 1의 구성요소를 추가·한정하여야 할 수 있다.
2. **본 문서는 변리사의 검토를 거치지 아니한 기술 초안이다.** 청구항의 문언, 종속 관계,
   기재요건(특허법 제42조 제4항) 충족 여부는 대리인이 확정하여야 한다.
3. **명세서에 기재된 모든 수치는 계산값이며 실측값이 아니다.** 명세서 [0022]에 그
   취지를 명기하였다. 실시예를 실측값으로 보강하면 기재요건 및 진보성 주장이 강화된다.
4. **UU-1(나노결정질 자심의 제작 가능성)** 이 미해결이다. 청구항 19는 나노결정질 리본을
   한정하고 있으므로, 조달이 불가능한 것으로 판명되면 해당 청구항의 보정이 필요하다.

## 재생성

```bash
python3 make_patent_figs.py     # 도 1 ~ 도 18
python3 make_drawing_pdf.py     # 도면 PDF 편집
python3 make_spec.py            # 명세서 (.md + tables.json)
python3 make_hwpx.py            # 명세서 (.hwpx)
```

## 명세서 구성 확인

* 단락번호 [0001] ~ [0081]
* 청구항 26항 (장치 독립항 1항, 방법 독립항 2항, 검증 방법 독립항 1항, 종속항 22항)
* 표 3개 (차폐 전달함수 / 주파수별 구동 제원 / 자심 재료 비교)
* 부호의 설명 56개 항목, 도면 18매와 완전히 일치
