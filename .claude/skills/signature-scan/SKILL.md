# signature-scan — F1~F5 실패 지문 판별

## 무엇을 하는가

전해 실험 로그를 `CLAUDE.md` §2.1의 표준 지문 규칙으로 대조해, 어떤 실패 경계에 접근 중인지
판별한다. 판별 원칙은 **단일 임계값이 아니라 "방향 × 시간척도 × 가역성"의 조합**이다.

이것은 Gate 3에서 구현될 PHM의 v0 프로토타입이며, 여기서 축적되는 판별 사례가
**PHM 알고리즘 특허(L1 후보 F)의 실증 근거**가 된다.

## 절차

### 1단계 — 컬럼 매핑 확인

스크립트는 흔한 이름을 자동 인식하지만(`v_cell`, `vcell`, `voltage`, `전압` 등),
실패하면 `--map` 으로 지정한다. **매핑이 틀리면 판정 전체가 무의미하므로 먼저 확인한다.**

```bash
python3 .claude/skills/signature-scan/scripts/scan.py <파일.csv> --list-columns
```

### 2단계 — 판별 실행

```bash
python3 .claude/skills/signature-scan/scripts/scan.py <파일.csv> [--time-col t] [--map v_cell=Ecell,dp=deltaP]
```

의존성 없음(표준 라이브러리만). 출력은 모드별 점수·근거·시간척도다.

### 3단계 — 해석 (스크립트가 하지 못하는 것)

점수를 그대로 옮기지 말고 다음을 판단해 보고한다.

- **운전 이력과 대조** — 콜드존(<35 °C) 통과, 부하 급변, 정지·재기동이 있었는지.
  F2는 이력 없이는 성립하기 어렵다.
- **가역성 확인** — 고유량 퍼지 후 회복되면 F1, 회복 안 되면 F2. 데이터에 퍼지 구간이
  없으면 "가역성 미확인"으로 남긴다.
- **시간척도 정합** — F5(만성)는 수백 시간 단위다. 100시간 데이터에서 F5 만성을 단정하지 않는다.
- **센서 드리프트 배제** — F4는 스크러버 전/후단 비율이 함께 움직여야 실제 슬립이다.

### 4단계 — 보고

```
## signature-scan — <파일> (n행, t=0~120 h)

**판정: F1 접근 징후 (중간 신뢰도)** · 부차: F5 만성 드리프트 관측

| 모드 | 점수 | 근거 | 시간척도 부합 |
|---|---|---|---|
| F1 | 0.72 | ΔP 이동분산 3.4배↑, HFR 평탄(기울기 0.001) | ✔ 분~수십 분 |

### ⚠ F3 착시 점검
V_cell 하락이 관측되면 FE_H₂ 동반 상승 여부를 반드시 함께 보고한다.
전압만 보고 "성능 개선"으로 서술하는 것은 금지사항이다.

### 권고 조치
- 즉시: (예) 고유량 퍼지로 가역성 확인 → F1/F2 판별
- 운전: AEB Mode B(계면 회복) 또는 Mode C(염 제거) 전환 검토
- 데이터: 부족한 측정 항목 (예: 출구 NH₃ 미계측)
```

## 지문 규칙 요약 (CLAUDE.md §2.1)

| 모드 | 핵심 지문 | 시간척도 | 가역성 |
|---|---|---|---|
| **F1** 범람 | ΔP **맥동**↑ + HFR **불변** | 분~수십 분 | 가역 |
| **F2** 염 석출 | ΔP **계단**↑ + 국부 핫스팟 | 수 시간 | 비가역 |
| **F3** HER 우점 | FE 교차 + **V_cell 하락 착시** | 수 분 | 가역 |
| **F4** NH₃ 유출 | 출구 NH₃↑ + 질소수지 잔차 | 수십 분 | 가역 |
| **F5** 막 열화 | HFR 장기 드리프트(만성)/crossover 급증(급성) | 수백 시간 | 비가역 |

**F1↔F2 판별**: 맥동·가역(F1) vs 계단·비가역(F2). ΔP 상승만으로는 구분되지 않는다.
**해상 판별자**: 선체 IMU(Roll/Pitch) 컬럼이 있으면 ΔP와의 교차상관을 계산한다.
상관이 높으면 요동 유발 F1(운전 모드 전환으로 대응), 낮으면 젖음성 열화(Interposer 점검).

## 주의

- 이 스킬의 출력은 `[S] 시뮬레이션·해석`이다. Signature 라벨의 `[검증값]` 승격은
  Gate 3의 **의도적 경계 접근 실험**으로만 이루어진다.
- 점수는 상대 지표이지 확률이 아니다. "F1 확률 72%"로 쓰지 않는다.
- RM(4σ) 계산은 공분산 행렬이 확보된 뒤에나 가능하다. 이 스킬은 RM을 계산하지 않는다.
