## A. kordoc — 한글 문서 읽기·쓰기

설정은 이미 `.mcp.json` 에 들어 있다 (버전 4.25.22 고정, `KORDOC_OFFLINE=1` 로 외부 통신 차단).

1. 이 저장소로 Claude Code 세션을 새로 연다.
2. 처음 한 번 "kordoc MCP 를 허용할까요?" → 승인.
3. 기관 양식(.hwp/.hwpx)을 세션에 첨부하고 요청한다.
   - "이 사업계획서 양식 읽어서 항목별로 정리해줘"
   - "이 Markdown 초안을 HWPX 보고서로 만들어줘"
   - "개정 전·후 계획서 신구대조표 만들어줘"

참고
- kordoc 은 계정·API 키가 없고, 문서를 외부로 보내지 않는다(개발자 문서 기준).
- npm 의 `kordoc` 은 GitHub 저장소와 같은 개발자(chrisryugj) 가 배포한 정식 패키지임을 확인했다.
- 버전을 올릴 때는 `.mcp.json` 의 `kordoc@4.25.22` 를 새 버전으로 바꾼다.

## B. R&D 규정 검토 — claude.ai 커넥터 (아이패드 가능)

### 1) 법령 API 키(OC) 만들기 — 무료, Safari 에서 가능
1. https://open.law.go.kr → 로그인 → 사용자 가입
2. 가입 중 'API인증키(OC)' 칸에 **직접 정한 값**을 입력 → 중복확인 (비밀번호처럼 관리)
3. OPEN API 활용 신청 (법령·행정규칙 항목). 승인까지 시간이 걸릴 수 있다.

### 2) 커넥터 추가
1. claude.ai → 설정 → 커넥터 → **사용자 지정 커넥터 추가**
2. 이름: `국가R&D규정`
3. URL: `https://mcp.rndmanagers.org/mcp?oc=` 뒤에 본인 OC 값
4. 헤더는 비워 둔다 (키는 주소에만 들어감)

> 이 주소에 키가 들어가므로 **저장소·채팅·캡처에 남기지 않는다.** 그래서 `.mcp.json` 에도 넣지 않았다.

### 3) 써보기
- "국가연구개발혁신법상 연구수당 지급 한도와 근거 조문 알려줘"
- "과제 참여율 변경 시 협약변경 절차가 필요한지 조문 근거로 검토해줘"

### 주의
- 원격 서버는 개발자 개인이 운영한다. 질문 내용(과제명·금액 등)이 그 서버를 거치므로, **과제 고유 정보는 일반화해서** 묻는다.
- 공개 법령만 다루므로 특허 초안만큼 민감하지는 않다. 민감 과제는 나중에 PC 에 직접 설치(로컬 실행)로 전환할 수 있다.
- 결과는 검토 보조다. 정산·감사 사안은 전담기관 담당자 확인 필수.
