Anion Exchange Membrane Electrolyzer)

열구배·계면 미세환경 제어형 탄산수소암모늄 직접전환 AEM 시스템

────────────────────────────────────
1. 전문가 역할
────────────────────────────────────

당신은 다음 전문가로 구성된 통합 엔지니어링팀이다.

- 선박 배가스 처리 및 암모니아 포집 전문가
- RPB(Rotating Packed Bed) 질량전달 전문가
- 탄산수소염 직접 전기화학 전환 전문가
- AEM/BPM 막·이오노머 전문가
- Ni 단일원자 촉매 및 GDE/MPL 전문가
- 전기화학 스택·열유동·CFD 전문가
- 선박 공정안전·HAZOP·선급 대응 전문가
- 합성가스·메탄올·엔진 연료 전문가
- 기술경제성·LCA·MRV 전문가
- 특허 청구항 및 기술사업화 전문가
- 신뢰성물리(Reliability-Physics)·PHM·가속수명 전문가   ← V4.1 추가
- Digital Twin·베이지안 상태추정·MPC 전문가              ← V4.1 추가

각 분야를 독립적으로 검토한 뒤, 상충되는 요구조건을 통합한
하나의 실행 가능한 설계안을 제시한다.


────────────────────────────────────
2. 설계 임무
────────────────────────────────────

다음 공정을 대상으로 선박 적용이 가능한 저전력 CO 중심
합성가스 시스템을 설계하라.

5 vol% CO₂ 선박 배가스
→ 배가스 전처리
→ 5 wt% 암모니아수 RPB 포집
→ NH₄HCO₃ 중심 포집액 조정
→ 열탈거 없는 직접 전기화학 전환
→ CO 중심 생성가스 정제
→ 외부 H₂ 정밀 혼합
→ 보일러·엔진 혼소·메탄올 합성

설계의 우선순위는 다음 순서를 따른다.

1. 안전성과 탄소·질소 수지
2. CO 선택도와 장기 안정성
3. 선박 전력부하 최소화
4. 장치 크기와 CAPEX
5. 운전 유연성과 유지보수성
6. 특허 차별성과 사업화 가능성

성능의 정의(V4.1): "순간 최고 성능"이 아니라
실패 경계로부터의 거리(RM)가 확보된 상태의 지속 성능을 성능으로 정의한다.


────────────────────────────────────
3. 절대 설계 원칙
────────────────────────────────────

다음 원칙을 반드시 준수한다.

① 전해조를 "발전기" 또는 일반 "AEM 수전해조"라고 부르지 않는다.
   권장 명칭: "탄산수소암모늄 포집액 직접 CO 전환 전해조"

② 전류밀도가 합성가스 조성을 직접 결정한다고 가정하지 않는다.
   CO₂ + H₂O + 2e⁻ → CO + 2OH⁻
   2H₂O + 2e⁻ → H₂ + 2OH⁻
   다른 생성물이 무시될 경우: H₂/CO ≈ FE_H₂ / FE_CO

③ 전해조는 CO 중심 기본부하로 운전한다.
   고수소 합성가스가 필요한 경우 HER를 과도하게 촉진하지 않고
   외부 LNG 개질수소, 암모니아 분해수소 또는 청정수소를 혼합한다.

④ 40℃를 최초 기준점으로 사용하되 절대 최적온도로 단정하지 않는다.
   DOE 온도: 35 / 40 / 45 / 50℃

⑤ 비질소계 AEM, EDTA, Water-in-Salt를 동시에 적용하지 않는다.
   각 기술은 독립 시험항목으로 분리하고, 기준 셀보다 성능과
   안전성이 개선된 경우에만 다음 단계로 편입한다.

⑥ 문헌 실험값을 선박용 보증값으로 전환하지 않는다.
   모든 수치에는 다음 중 하나의 상태를 표시한다.
   - [검증값]: 동일 조건의 공개 실험 또는 자체 실험으로 확인
   - [설계목표]: 개발과정에서 달성해야 할 수치
   - [가설]: 아직 직접 검증되지 않은 기술적 추론
   - [제외]: 선박 적용성이 부족하여 기본설계에서 제외
   - [추가시험]: 데이터가 부족해 DOE가 필요한 항목
   (구 문서 태그 호환: [M]=검증값, [H]=설계목표 또는 가설,
    [S]=시뮬레이션 근거 설계목표, [L]=문헌 참고치 — 보증값 아님)

⑦ 검증된 대조군을 버리지 않는다. (V4.1)
   음극 촉매는 Ni–N–C SAC를 목표 촉매로 하되,
   Ag/GDE 검증 기준 셀(control arm)을 모든 게이트에서 병행 운전한다.
   신규 소재는 대조군 대비 통계적으로 유의한 개선을 보일 때만 편입한다.

⑧ 실패 모드는 표준 택소노미만 사용한다. (V4.1)
   F1 Flooding(범람) / F2 Salt Precipitation(염 석출) /
   F3 HER Dominant(수소 우점 전이) / F4 NH₃ Slip(암모니아 유출) /
   F5 Membrane·Interposer Degradation(막·삽입층 열화)
   — PHM 소프트웨어, HAZOP, 선급 문서, 사업 문서에서 ID를 통일한다.

⑨ 낙관 단일 시나리오로 재무를 작성하지 않는다. (V4.1)
   모든 경제성 산출은 Base(본 레시피의 [설계목표] 기준)와
   Upside(상위 가설 통과 시)로 이원 표기한다.


────────────────────────────────────
4. V4.1 기준 운전 레시피
────────────────────────────────────

다음 조건을 최초 설계 기준으로 사용한다.

[배가스]
- CO₂: 약 5 vol% / 산소·수분·SOx·NOx·PM 포함
- 전처리 출구온도: 15~25℃
- 포집설계 범위: 80~90% [설계목표]
- RPB는 rpm만으로 설계하지 말고 β-factor, 반경, L/G,
  F-factor, KGa, HTU, 압력강하를 함께 사용한다.

[흡수액]
- 암모니아수: 5 wt% (초기 NH₃ 환산 약 2.9 M)
- 목표 포집액: 1.5~2.5 M NH₄HCO₃ 중심 [설계목표]
- 실제 분석항목: TIC, TAN, NH₄⁺, HCO₃⁻, CO₃²⁻, carbamate,
  sulfate, nitrate, chloride, 금속, suspended solids
- 포집액 조성을 NH₄HCO₃ 단일물질로 가정하지 않는다.

[전해조]
- 기준온도: 40±2℃ / 온도 DOE: 35/40/45/50℃
- 시운전 전류밀도: 50 mA/cm² / 기본부하: 100 mA/cm²
- 200 mA/cm²: 단기 성능시험에만 사용
- 음극 촉매(목표): Ni–N–C 단일원자 촉매, 약 1 mg/cm²
- 음극 촉매(대조군): Ag/GDE 1 mg/cm² — 전 게이트 병행 [원칙 ⑦]
- 촉매층 PTFE 중심값: 20 wt% / DOE: 10/20/30 wt%
- 기준막: ether-free 피페리디늄계 상용 AEM
- 기준 비교막: BPM
- 실험막: 포스포늄·설포늄·복합 headgroup AEM
  (코발토세늄계는 음극 분극 안정성 시험(UT-07) 통과 전 [추가시험])
- EDTA DOE: 0/5/10/20 mM
- Water-in-Salt: 기본설계 [제외], 실험실 대조군 전용

[개발 목표] — 전부 [설계목표], 보증값 아님
- FE_CO ≥75% @ 100 mA/cm² (도전목표 ≥80%, 장기목표 ≥90% [가설])
- 셀 전압 ≤3.5 V @ 100 mA/cm²
  (1.0~1.2 V급 극저전압은 AOR 결합 [가설]로 분리 관리 — UT-01,
   Base 재무는 3.5 V 기준으로만 작성)
- 탄소수지 closure: 95~105% / 질소수지 closure: 95~105%
- 연속운전: 1차 100시간 → 2차 500시간 → 파일럿 전 1,000시간
- 성능저하 기준: FE_CO, 셀 전압, HFR, 차압, 접촉각,
  NH₃ 손실, carbon crossover — F1~F5 Signature 맵과 연동


────────────────────────────────────
5. MECE 설계 필라
────────────────────────────────────

Pillar 1. 배가스 전처리·RPB 포집
(V4.0 원문 유지)
- PM 제거 / SOx·NOx 관리 / 응축수 분리 / 배가스 냉각
- 암모니아수 RPB 포집 / water-wash 기반 NH₃ slip 저감
- 흡수액 농도·C/N 자동제어 / sulfate·nitrate bleed 처리
- 포집률뿐 아니라 kg-CO₂/kWh와 NH₃ 손실을 최적화
필수 출력: 블록 흐름도, 장치·계측기 목록, 물질수지,
RPB 설계변수 표, 포집액 정상·비정상 조성 범위

Pillar 2. 촉매·경사형 MPL 계면 (Ag 대조군 병행)
적층구조:
NH₄HCO₃ 유로 → 막/이오노머 접촉층 → 촉매층(Ni-SAC 목표 / Ag 대조군)
→ 경사형 미세기공층 → 소수성 GDL → CO/H₂ 생성가스 유로

삽입층은 단일 균질막으로 설계하지 않는다.
- 막 측: 친수성·이온접촉 유지 / 촉매층: i-CO₂ 체류·반응면적
- GDL 측: 소수성·기포배출 / 공극률·공극크기·PTFE 두께방향 구배
- flooding과 dry-out 동시 억제
측정항목: 접촉각(초기·운전 후), 기체투과도, breakthrough pressure,
차압, EIS/HFR, FE_CO·FE_H₂, Ni/Ag 용출, PTFE·이오노머 열화, 염 침착

Pillar 3. 막 아키텍처 비교 (4-Arm으로 확장, V4.1)
동일 전극·유량·온도에서 비교:
- Arm A: BPM + 촉매 + 경사형 MPL — 문헌 기준 셀
- Arm B: 상용 피페리디늄 AEM + 촉매 + 경사형 MPL — AEM 목표 셀
- Arm C: 실험막(포스포늄·설포늄·복합) — 차세대 소재 셀
- Arm D: C³-MEA(BPM Local-H⁺ 국소 CO₂ 재생 + GRI형 반응장)
         — 차세대 아키텍처 셀 [가설], Arm A의 BPM 자산 재활용
비교 항목: OH⁻/HCO₃⁻/CO₃²⁻ 전도, carbon crossover,
NH₃/NH₄⁺ crossover, 수분이동, 막팽윤, 면저항, 가스 crossover,
셀 전압, 장기 화학·기계 안정성
"OH⁻만 막을 통과한다"는 가정을 금지한다.

Pillar 4. 열구배 관리 (세대 분리 + ΔT 정의 분리, V4.1)
ΔT는 두 가지를 구분해 정의한다:
(a) 막 계면 ΔT — 활성면 내 편차, 1세대 목표 3℃ 이하
(b) 채널 간/양극-음극 유체 공급온도차 — 2세대 비등온 DOE 변수
1세대: 40℃ 등온 기준
- 음극/양극 입구·중앙·출구 온도, 막 가장자리 hotspot 감시
- 셀별 전압·HFR 기반 가상온도·수화상태 추정
- 초기 제어: 40±2℃ / 활성면 ΔT ≤3℃ / 경보 50℃ / 긴급정지 55℃
2세대: 비등온 검토 — 음극 38~42℃ / 양극 50~60℃ /
공급온도차 최대 20℃ DOE. 추가 열소비를 에너지수지에 포함.

Pillar 5. 전기화학·동적제어 + AEB (V4.1 확장)
폐루프 입력: 선내 가용전력, 셀별 전압, 전류밀도, FE_CO 추정,
CO/H₂ 실시간 분석, pH, TIC/TAN, conductivity, HFR, 온도분포,
catholyte 차압, 생성가스 유량, NH₃ slip
제어 우선순위:
1. 안전 인터록
2. 신뢰성 마진 RM ≥ 4σ 유지 (V4.1 — 4σ 미달 방향성 감지 시 선제 개입)
3. 온도·막 수화상태
4. pH·bicarbonate 보존
5. flooding·dry-out 회피
6. FE_CO 유지
7. 전력부하 추종
8. 생산량 조정
전류밀도는 생산량 제어에, 제품 H₂/CO 조성은 외부 H₂ trim에 사용한다.
운전 모드(AEB, pseudo-steady-state):
- Mode A Production(기본부하) → Mode B Interface Recovery(저전류·
  적응 펄스·수화 회복) → Mode C Salt Clearing(유량·압력·pH transient)
- 고정 펄스(예: 100/20 ms)는 출발점일 뿐이며, 상태추정 연동
  self-adaptive pulse가 steady-state 대비 우위임을 검증 후 채택 [추가시험]

Pillar 6. EDTA·첨가제 모듈
(V4.0 원문 유지 — 독립 bypass 모듈, 0/5/10/20 mM,
채택 7조건 전부 만족 시에만 편입, 미달 시 [제외]/[추가시험])

Pillar 7. 생성가스·외부 H₂·최종 활용
(V4.0 원문 유지 — 기액분리→응축→NH₃ 제거→mist 제거→건조→분석→
외부 H₂ 혼합→소비처. 모드별 조성은 초기 시험점.
전해조 내부 HER 증가로 메탄올용 H₂를 생산하지 않는다.)

Pillar 8. 안전·HAZOP (F 택소노미 연동, V4.1)
HAZID/HAZOP 대상 위험(각각 원인→결과→예방→감지→자동보호→
수동대응→잔여위험으로 분석):
NH₃ 누출, CO 누출, H₂ 화재·폭발, O₂ 혼입, 막 pinhole·가스
crossover(F5 급성), 고온점·국부건조(F3/F5), RPB 회전체 진동,
배관 부식, 탄산염 결정(F2), 정전·blackout, 선박 동요·액체분배
불균일(F1 유발)
- 기존 예비 HAZOP 시나리오 S1~S13을 시드로 사용하고
  가이드워드 전수 순회로 확장한다.
- 해상 전용 항목(S13 Storm Mode: IMU–ΔP 상관 임계 시 저부하
  자동 전환)은 선급(AiP) 심사 대응 항목으로 명시한다.
- HAZOP 산출물 승인 없이는 전기 인가를 금지한다(Gate 0 조건).

Pillar 9. PHM·Digital Twin·신뢰성물리 (V4.1 신설)
- 7D 상태공간: X = [T_bulk, ΔT_MEA, j, C_NH₄HCO₃,
  pH_interface, a_w, Ψ_interposer]
- 반응벡터: Y = [FE_CO, FE_H₂, V_cell, 탄소이용률, ASR/HFR,
  NH₃ slip, 열화율]
- F1~F5 Failure Signature 맵: 판별은 단일 임계값이 아니라
  방향×시간척도×가역성 조합으로 한다. 최소 규칙:
  · F1: ΔP 맥동↑ + HFR 불변 + 가역 (IMU 상관으로 요동성 구분)
  · F2: ΔP 계단·비가역 + 국부 핫스팟 + 콜드존/농축 이력
  · F3: FE 교차 + V_cell 하락 착시(전용 경보 필수)
  · F4: 출구 NH₃↑ + 질소수지 잔차 (전/후단 비율로 드리프트 배제)
  · F5: HFR 수백 시간 드리프트(만성) / crossover 급증(급성)
- RM = min_i Mahalanobis d(X_op, F_i), 공분산에 공정변동·센서오차·
  모델불확도·드리프트 포함. RM ≥ 4σ [설계목표].
  4σ 통과는 "고장확률 0"이 아니라 가정 분포에서의 설계 여유다.
- Signature 라벨은 Gate 3에서 의도적 경계 접근 실험으로 획득한다.
- RUL: Eyring·Competing-risk 병행 비교, F5 만성 드리프트가 주 입력.


────────────────────────────────────
6. 필수 계산식
────────────────────────────────────

(V4.0 원문 유지)
n_CO = I × FE_CO / (2F)
n_H₂ = I × FE_H₂ / (2F)
H₂/CO ≈ FE_H₂ / FE_CO
n_CO₂,converted ≈ n_CO (formate·carbonate crossover·미확인 생성물 별도)
Carbon efficiency = 제품 탄소 / (유입 무기탄소 − 회수 가능 미반응 탄소)
P_system = P_stack + P_RPB + P_blower + P_pump + P_chiller/heater
         + P_gas purification + P_H₂ compression + auxiliary
SEC = 총 시스템 전력 / 순 전기화학 전환 CO₂량
Net CO₂ reduction = 공인 저장·대체 효과 − 전력배출 − NH₃ 제조배출
                  − 외부 H₂ 배출 − 보조연료 배출 − 재배출
(재연소 시 "포집 제거량"과 "단기 재순환량"을 구분)

V4.1 추가:
RM = min_i √((X_Fi − X_op)ᵀ Σ⁻¹ (X_Fi − X_op))
CE_system = 판매 제품 탄소 / 포집 탄소  (시스템 최상위 KPI)
전력 원단위 검산(패러데이): 1 Nm³ CO = 44.6 mol × 2e⁻ = 2,390 Ah
→ Base(3.5 V·FE 75%) ≈ 11 kWh/Nm³-CO [설계목표 기준 상한]
→ 3.0 V·FE 90% ≈ 8 kWh/Nm³-CO
→ 1.0~1.2 V·FE≈100%(AOR [가설]) ≈ 2.5~3.5 kWh/Nm³-CO
어떤 전력 원단위 주장이든 위 검산과 함께 제시한다.

7. 시험 및 Go/No-Go 게이트 (UT 연동, V4.1)
────────────────────────────────────

Gate 0 — 착수 조건 (V4.1 신설)
- HAZOP 산출물 5종 승인 (미승인 시 전기 인가 금지)
- UT-00 수지 폐합: carbon/ion/water closure ≥95% 계측체계 확립
- 계측 MSA(반복성·재현성) 완료
NO-GO: closure 미계측 상태의 성능 주장 금지

Gate 1 — 5~25 cm² 단전지
- 합성 2.5 M NH₄HCO₃, 40℃, 50/100/200 mA/cm²
- Arm A/B(+C) 비교, Ag 대조군 병행, 최소 100시간
GO: FE_CO ≥75% @100 mA/cm² / 셀 전압 ≤3.5 V /
탄소·질소 closure 95~105% / 치명적 flooding·막박리 없음
연동 UT: UT-02(삽입층 구배), UT-03(막 후보 쿠폰),
UT-07(실험막 음극 분극 안정성 — soak 시험만으로 편입 금지)

Gate 2 — 실제 RPB 포집액
- 5% CO₂ 모사가스, 5 wt% NH₃, SOx·NOx·O₂·수분 단계 투입
- 실제 포집액 vs 합성액, 최소 500시간
GO: FE_CO 감소 허용범위 이내 / 불순물 축적 관리 /
NH₃ slip·금속용출 관리 / 포집·전환 통합 탄소수지 확보

Gate 3 — 100~1,000 cm² 모듈
- 다점 온도센서, 셀별 전압, HFR, 온도장·유동분배, 1,000시간
- F1~F5 Signature 라벨 획득(의도적 경계 접근, rollback 조건 포함)
GO: hotspot 없음 / 셀별 전압편차 관리 / 평균 FE_CO 유지 /
성능저하 원인 분해 가능 / 유지보수 가능 모듈구조
연동 UT: UT-04(AEB vs steady-state A/B), UT-08(pH 스윙 수지 —
Arm D 판정)

Gate 4 — 200 kg/day → 2 TPD → 선박 → 10 TPD
각 단계: 설치면적, 중량, 전력, 냉각부하, 포집액·NH₃ inventory,
생산가스 유량, CAPEX/OPEX(Base/Upside 이원), 정비주기,
선급·OEM 승인항목, 단계별 중단조건
선상 단계 GO에 RM ≥ 4σ 유지율과 PHM 오경보율(false-safe rate)을 포함한다.

8. 특허전략 (계층형, V4.1)
────────────────────────────────────

특허의 중심을 단순 소재조합이 아니라 제어 가능한 시스템효과에 둔다.
청구 구조는 3계층으로 배치한다.

L1 — 기능 정의 독립항 (회피설계 방어, 수치 비의존):
후보 A: 다점 계면온도, HFR, pH 및 C/N을 이용해 전류밀도와
catholyte 유량을 폐루프 제어하는 탄산수소암모늄 직접전환 시스템.
후보 B: 막 측 친수성 영역과 가스배출 측 소수성 영역을 포함하는
두께방향 공극·습윤도 경사형 전극.
후보 C: CO 중심 기본부하 전해와 외부 H₂ trim을 독립 제어하는
목적별 합성가스 제조시스템.
후보 D: AEM/BPM/APMA 카세트를 동일 스택 하우징에서 교체 가능한
모듈형 막·전극 구조.
후보 E: 온도 hotspot, HFR, 차압, 가스조성으로 flooding, dry-out,
막 pinhole, 가스 crossover를 판별하는 선박 안전제어.
후보 F(V4.1): 복수 실패 경계와 공분산 기반 확률거리(RM)를 산출해
운전점을 유지·회복시키는 신뢰성 제어 시스템 및 그 폐루프
(Reaction Field–PHM 결합 청구).

L2 — 수치 한정 종속항 (무효화 방어):
35~50℃ / 50~200 mA/cm² / Ni-SAC / 경사형 MPL / PTFE 함량 /
EDTA 선택투입 / 포집액 bypass / 외부 H₂ 혼합 —
단, 수치 한정은 해당 DOE·UT 통과 후 확정하며 검증 전 고정을 금지한다.

L3 — 공정·제어 종속항:
NH₃/CO/H₂/O₂ 인터록 / AEB Mode A/B/C / Storm Mode /
Signature 기반 판별 규칙 / RUL 연동 정비
