# SEION 10 TPD 저전력 암모니아 RPB-AEM 하이브리드 CCU 플랫폼 사업화 계획서 (Rev.1)

**MECE 기반 통합 사업화 전략 | Base–Upside 이원 시나리오 | 4σ Safe Operating Envelope | 선박 온보드 탄소 선순환 플랫폼**

> **개정 노트 (Rev.0 → Rev.1) — 기술 문서 교차검증 반영 6건**
> 1. 전력 원단위의 숨은 전제(UT-01 극저전압)를 명시하고 **Base/Upside 이원 시나리오**로 재구성
> 2. F1~F5 실패 모드 정의를 **PHM·HAZOP 표준 택소노미로 통일**
> 3. 사업화 일정을 기술 로드맵(54개월 TRL 체계)에 **재베이스라인** — Upside 단축 조건 별도 명시
> 4. AEM 막 공급망을 **후보(코발토세늄)–대안(PAP계) 이원 표기**로 수정
> 5. 모든 성능·경제성 수치에 **증거 태그([M]/[S]/[H]) 적용** + 근거 시트(부록 B) 신설
> 6. 세부 수치 정합화(GDE 접촉각·Payback 용어 구분) 및 오기 수정
>
> **증거 태그**: [M] 실측 / [S] 시뮬레이션 / [H] 가설·설계목표. 실측 전 수치는 보증값이 아니다.
