# 자이로이드 메타물질 DIW 설계 — 팽창일라이트 + 알지네이트 + C₃₈H₇₈O

도구: `tools/materials/seion_gyroid.py` · 설정: `tools/materials/gyroid_seion_config.json`
등급: **P0(모델 계산)** — 설정값 다수가 '가정'이므로 아래 수치는 *방법과 경향*을 보여주는 예시다.

## 1. 계산 흐름

| 단계 | 모델 | 산출 |
|---|---|---|
| 형상 | 자이로이드 레벨셋 `sin x cos y + sin y cos z + sin z cos x`, 골격형(f≤t)·막형(\|f\|≤t) | 상대밀도 φ, 벽두께·기공 크기, 연결성, 하향 면 각도 분포 |
| 물성 | 복셀 FEM(36³, 2×2×2 단위포) → Gibson–Ashby `E/Es = C·φⁿ` | 골격형 n_E = 2.32, 막형 n_E = 1.74 (문헌 범위) |
| 페이스트 | 질량% + 성분 밀도 → 부피분율 | 밀도 1.53 g/cm³, 물 53.7 vol% |
| 압출 | Herschel–Bulkley 원관유동(정확 적분) | 노즐 벽 전단응력·압출압력 |
| 적층 | `H_max = √3·τ0 / (ρ g SF)` | 쌓을 수 있는 높이, 필요한 항복응력 |
| 오버행 | 층간 밀림 `h·tanα ≤ 0.5w` 와 재료 한계각 중 큰 값 | 받쳐지지 않는 하향 면 비율 |
| 후처리 | 건조 5 %·소성 8 % 선수축(가정), 알지네이트·왁스 연소 | 출력 배율 1.144, 소성 후 벽 기공률 0.54 |
| 최적화 | Optuna NSGA-II, 제약 9개 | 파레토 해, 3가지 추천안, 출력 가능 범위 |

## 2. 계산으로 알게 된 것

1. **현재 가정 배합(τ0 = 300 Pa)으로는 30 mm 부품을 쌓을 수 없다.** 수축 보정 후 출력 높이 34.3 mm 에 필요한 항복응력은 **446 Pa** (안전율 1.5). → 레올로지 실측이 최우선. 부족하면 알지네이트 Ca²⁺ 가교(분무·배스)로 출력 중 굳히거나 부품 높이를 낮춘다.
2. **자이로이드의 하향 면 각도 분포는 t·단위포 크기와 무관하다** (45° 초과 하향 면 ≈ 11.7 %, 60° 초과 ≈ 4.4 %). 형상 파라미터로 오버행을 줄일 수 없고, 층 높이·페이스트 지지력·출력 방향으로만 조절된다. → **오버행 시험편(15~60° 경사벽)** 출력으로 재료 한계각을 먼저 측정.
3. **출력 가능 범위에서는 골격형이 막형보다 우세.** 막형은 단위포 8 mm 이하에서 막 두께가 필라멘트 폭(0.84~1.19 mm)보다 얇아져 대부분 탈락.
4. 단위포는 부품 안에 4개 이상(최종 7.5 mm 이하) 들어가야 격자 유효물성이 성립 — 이 제약이 없으면 최적화가 단위포를 키워버린다.

## 3. 가교 시나리오(항복응력 ×2 가정)의 추천안

| 추천 | 형태·t | 최종 단위포 | 노즐 / 층높이 / 속도 | φ | k_rel | E_rel | 소성 후 총 기공률 | 출력시간 |
|---|---|---|---|---|---|---|---|---|
| 단열 우선 | 골격형 −0.94 | 6.8 mm | 1.19 / 0.94 mm / 11 mm/s | 0.19 | 0.079 | 0.023 | 0.91 | 10 분 |
| 균형(무릎점) | 골격형 +0.32 | 4.7 mm | 0.84 / 0.66 mm / 13 mm/s | 0.60 | 0.435 | 0.318 | 0.72 | 57 분 |
| 강성 우선 | 골격형 +1.00 | 7.3 mm | 1.19 / 0.88 mm / 22 mm/s | 0.83 | 0.719 | 0.629 | 0.62 | 25 분 |

k_rel·E_rel 은 *벽 재료 대비* 비율. 절대값은 같은 배합·공정의 꽉 찬 시편 실측(E_s, k_s)을 설정에 넣으면 자동 계산된다.

## 4. 실측으로 바꿔야 할 값 (우선순위)

1. **유변물성** τ0·K·n — 회전 레오미터 전단속도 스윕 → `seion_gyroid.py rheo data.csv`
2. **가교 전/후 항복응력** → `crosslink_yield_multiplier`
3. **오버행 한계각** — 경사벽 시험편
4. **건조·소성 선수축** — 시편 치수 측정
5. **C₃₈H₇₈O 녹는점**(DSC) — 출력 온도가 근처면 레올로지 급변
6. **팽창 일라이트 겉보기 밀도·입자 내부 기공률** — 피크노미터, 수은압입
7. **벽 재료 E_s, k_s, 강도** — 꽉 찬 시편
8. **프린터 사양** — 노즐 내경, 최대 압력, 속도 범위

설정을 바꾸면 `optimize` 를 다시 돌리면 된다. 보정표(`data/gyroid_calibration.json`)는 형상에만 의존하므로 재계산 불필요.

## 5. 명령 예

```bash
PY=~/.seion-venv/bin/python; T=tools/materials/seion_gyroid.py
$PY $T rheo rheometer.csv                     # 레올로지 피팅
$PY $T paste                                  # 배합 → 밀도·기공률
$PY $T optimize --trials 400                  # 다목적 최적화 (mode: insulation|lightweight|stiffness)
$PY $T evaluate --kind network --t -0.45 --cell 5.4 --nozzle 0.84
$PY $T stl --kind network --t -0.45 --cell 5.43 --out gyroid.stl   # 수축 보정 STL
```

## 6. 한계

- 복셀 FEM 은 z 방향 1축 하중·선형탄성. 파괴·좌굴·이방성(층간 약화)은 미포함 — 압축 시험으로 확인.
- 적층 판정은 정적 항복응력 기준(시간에 따른 구조화·가교 속도 미반영).
- 오버행은 면적 비율 지표로, 실제 처짐은 시험 출력으로 판단.
- 출력 방향 회전(예: [111] 방향 적층)으로 오버행 분포를 바꾸는 최적화는 아직 없음.
